NettyHttp3Configuration

class NettyHttp3Configuration(source)

Configuration for the HTTP/3 (QUIC) transport in the Netty engine.

Options defined here apply only to the HTTP/3 endpoint. They have no effect on HTTP/1.1 or HTTP/2 connectors.

An instance of this class is provided to the lambda passed to io.ktor.server.netty.NettyApplicationEngine.Configuration.enableHttp3.
